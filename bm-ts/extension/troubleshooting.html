Troubleshooting Guide

Solutions to common issues with BirthdayMessaging

Tip: Most issues are resolved by reloading the extension. Go to chrome://extensions/, find BirthdayMessaging, and click the reload (↺) button, then reopen the popup.

Extension Won't Load / Popup Is Blank

Symptoms: Clicking the 🎂 toolbar icon opens a blank or broken popup.

  1. Go to chrome://extensions/ and confirm BirthdayMessaging is enabled (toggle is blue).
  2. Click Details → the reload (↺) icon to force-reload the extension.
  3. Close and reopen the popup.
  4. If still blank, uninstall and reinstall the extension from the Chrome Web Store.

Can't Log In

Symptoms: Login form submits but shows an error, or the page spins indefinitely.

Error message What to do
"Invalid credentials" Double-check your email and password. Passwords are case-sensitive.
"Account locked" Too many failed attempts. Wait 15 minutes, then try again.
"Network error" Check your internet connection and try again in a moment.
Spinner never stops The backend may be temporarily unreachable. Try again in a few minutes.

If you're unsure of your password, use Forgot password? on the login screen to reset it. If the issue persists, try clearing the extension's storage: go to chrome://extensions/ → BirthdayMessaging → Details → Clear site data.

Password Reset Email Never Arrives

  1. Check your spam / junk folder — the email is sent from our SendGrid domain.
  2. Wait up to 5 minutes; delivery can occasionally be delayed.
  3. Make sure you entered the correct email address (the one used to register).
  4. Request a new reset link — previous links expire after 1 hour.
  5. If the problem persists, contact support with your registered email address.

Automation Isn't Running / Birthdays Being Missed

Symptoms: No new entries in Message History; birthdays are being missed.

Work through this checklist:

  1. Automation status — Go to the Scheduling tab → Automation Settings and confirm the status shows Active. If it shows “Emergency Stop active”, click the clear button to resume. Also check the Automation Engine toggle on the Home tab.
  2. Schedule is enabled — Go to the Scheduling tab and verify at least one schedule exists under Birthday Message Schedule.
  3. Template exists — Go to the Templates tab → Message Templates and confirm you have at least one saved template.
  4. Chrome was open — The extension requires Chrome to be running at the scheduled check time. If Chrome was closed, the next check will run at the next scheduled interval.
  5. Max messages not reached — Check Max Messages Per Run in Automation Settings (Scheduling tab). If set too low, messages may have been capped before reaching all birthdays.
  6. Facebook is logged in — Open a Facebook tab and confirm you're logged in to your Facebook account.

Some Contacts Show "Month Only" and Don't Receive Messages

Symptoms: Certain contacts display a "Month only — messaging paused" label and never appear in Message History.

This is expected behaviour. Facebook only reveals exact birthday dates for friends whose birthday is within the next few days. For all other friends, only the birth month is visible. BirthdayMessaging automatically blocks messaging for these contacts to avoid sending on the wrong day.

How to fix it:

  1. Re-scan closer to the birthday: Open facebook.com/friends/birthdays, then go to Contacts → Import → Facebook and re-import. When the friend's birthday is near, Facebook shows the exact date and BirthdayMessaging will automatically update the contact.
  2. Edit manually: Open the Contacts tab, click Edit on the contact, and enter the correct birthday. This removes the month-only restriction and messaging will resume.

Duplicate Messages / Messages Sent to Wrong People

Symptoms: Some friends receive more than one message; wrong friends are being messaged.

  1. Check Message History to see exactly who was messaged and when.
  2. If duplicates occurred today, click Clear Sent-Today List in Automation Settings (Scheduling tab) to reset the deduplication list, then reload Chrome before the next run.
  3. Review your Contacts list for duplicate entries (the same person added twice with different profile URLs).
  4. If messages go to people they shouldn't, check your schedule's Days Before setting — a negative value sends a follow-up after the birthday, not on it.

Template Not Being Used / Wrong Template Sent

  1. Go to the Templates tab → Message Templates and confirm all intended templates are saved (not just drafted).
  2. Check the Days in Advance field on each template. A template set to “1 Day Early” will only match a schedule that sends 1 day before the birthday.
  3. If you have multiple templates, the extension picks one at random. Check Message History to see which template was used for each send.

Timeline Post Not Appearing on Facebook

Symptoms: Automation runs successfully but no post appears on the friend's timeline.

  1. Go to the Templates tab → Timeline Posts and confirm a post is created and enabled.
  2. Open Facebook manually and confirm you haven't been restricted from posting on friends' timelines (some privacy settings can block this).
  3. Check Message History — the history entry shows whether a timeline post was attempted alongside the message.

CSV Export Is Empty or Garbled

  1. Make sure you have messages visible in Message History before exporting. Apply filters first if your history is large.
  2. If the file contains odd characters, open it in Excel or Google Sheets using UTF-8 encoding (usually an option in the import dialog).
  3. To inspect the raw content, open the downloaded file in a plain text editor such as Notepad.

Stripe / Subscription Issues

Symptoms: Checkout doesn't open; subscription shows inactive after payment.

Symptom What to do
Checkout page won't open Disable popup blockers or ad blockers temporarily. Stripe's checkout opens in a new tab.
Subscription still "inactive" after payment Wait up to 1 minute for the webhook to process, then reload the extension. If still inactive after 5 minutes, contact support with your Stripe payment confirmation email.
Unexpected or duplicate charge Contact support immediately with your payment confirmation. Do not attempt to pay again.

Facebook Overlay Not Appearing

Symptoms: No floating sidebar appears when visiting Facebook.

  1. Make sure the extension is enabled in chrome://extensions/ and check that it has permission to run on Facebook pages.
  2. Hard-refresh the Facebook page (Ctrl+Shift+R) — the overlay injects when the page loads.
  3. Check for conflicts with other extensions that modify Facebook's UI. Try disabling other Facebook-related extensions temporarily.
  4. If the overlay was hidden with Escape, reload the page to bring it back.

Extension Becomes Slow Over Time

  1. Go to Message History and export/delete old history entries you no longer need.
  2. Reload the extension from chrome://extensions/.
  3. Restart Chrome.

Still Having Issues?

Before contacting support, collect the following to help us diagnose the issue quickly.
  1. Popup console errors: Right-click the popup → Inspect → Console tab. Copy any red error messages.
  2. Background service worker logs: Go to chrome://extensions/ → BirthdayMessaging → Details → click Inspect views: service worker. Check the Console tab for errors.
  3. Contact support with:
    • A description of the problem and steps to reproduce it
    • Any error messages from the console
    • Your registered email address
    • Your Chrome version (chrome://version/)
